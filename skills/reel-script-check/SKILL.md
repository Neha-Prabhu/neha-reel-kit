# Reel script check

Neha (Instagram: Neha Much) writes and shoots her own reels; edits are done later with neha-reel-kit. This skill works for any series or a one-off reel — don't assume a format. If she says the reel belongs to a series, follow that series' beats (ask once if you don't know them).

## Voice
- Natural, human, like she's talking to one friend; a little funny, a little sassy. No AI-sounding phrases.
- Indian and relatable scenarios, not generic/foreign ones.
- Keep her voice — fix only what matters.

## Inputs
Her script (often dictated — rough is fine) + what the reel is about (a website link, product, place, idea). If there's a link, open it yourself to check claims (counts, "free", times) and spot the best visuals. Optional: series/format, visual ideas she already has.

## What to return (one message, short)
1. **Hook verdict** — does the first 1.5 s create a gap or contrast? Slow setups cause a skip spike at 1–3 s. Give 2–3 alternative opening lines in her voice (relatable contrast works, e.g. "Pinterest DIYs are cute until they need 17 supplies").
2. **Tightened script** — changes marked inline. A good default shape: hook → one-line payoff → (series intro line if any) → what it is + 2–4 concrete examples she can point at → use-cases (each one a visual) → CTA / ending. Flag factual errors and wrong episode numbers.
3. **Visual plan table** — one row per line: line · what's on screen (A-roll / screen recording / pop image / cutout / B-roll) · notes (where she points or holds, keep-bg or cutout).
4. **Shot list** — A-roll tips (hold objects where the pop will go, leave head-room for a text hook, point at empty space), screen recordings to capture (phone, no URL bar or touch indicators if possible), any B-roll.
5. **Asset checklist with exact file names** — A-roll, `NN_<what>.png` per line, `_keep-bg` / `_cutout` suffixes, theme if any, text hook words if any, and how she'll give her exact spoken words (dictated transcript, or automatic transcription if available).

Don't put a text hook into the plan unless she gives one; offer options only.
